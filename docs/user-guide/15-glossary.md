# 15. Glossary

## Business and industry terms

| Term | Meaning |
|---|---|
| **MEP** | Mechanical, Electrical and Plumbing: the building services that Fixotec's supports hold up (pipes, ducts, cable trays) |
| **HVAC** | Heating, Ventilation and Air Conditioning |
| **AHU / ODU** | Air Handling Unit / Outdoor Unit (air-conditioning equipment) |
| **Mounting rail / strut channel** | A slotted steel channel (for example FXR 41×41) used to build support frames |
| **Trapeze** | A support made of a horizontal rail hung on two threaded rods |
| **Seismic support** | Bracing that holds services in place during an earthquake |
| **HDG** | Hot-Dip Galvanized: a zinc coating for corrosion protection |
| **DX51D / DD11** | Steel grades used for rails |
| **PMC** | Project Management Consultant |
| **OEM** | Original Equipment Manufacturer |
| **Consultant** | The design engineer or firm that specifies products in a project |
| **Contractor / MEP contractor** | The company that installs the services and buys the supports |
| **Distributor / Dealer** | A channel partner who buys at dealer price and resells |
| **Segment** | A service type: HVAC, Plumbing, Electrical, Fire Fighting, Multiple Services |
| **Sector** | A building or industry type: data centers, hospitals, high-rise, industrial |

## Commercial terms

| Term | Meaning |
|---|---|
| **Lead (LD-)** | A potential customer enquiry, before it is qualified |
| **Opportunity** | A qualified lead with a real chance of business |
| **RFQ (RFQ-)** | Request for Quotation: a customer's list of items to be priced |
| **Quotation (QT-)** | Fixotec's priced offer, with validity, terms, discount and tax |
| **Sales order (SO-)** | A confirmed customer order |
| **Price list** | Which price column a customer pays: STANDARD, CUSTOMER, DEALER or EXPORT |
| **Credit limit / credit hold** | The maximum unpaid amount allowed. Orders that exceed it are held |
| **Backorder** | Ordered quantity that can't be supplied from current stock |
| **Margin** | (Price − Cost) ÷ Price, as a percentage |
| **Ex-works** | Price excludes delivery; the customer collects from the factory (default: Pune) |
| **Validity** | How long a quotation's prices hold (default 15 days) |
| **Scheme / claim** | A distributor incentive programme / a request for the incentive payout |
| **Pipeline** | The value of open opportunities, RFQs and quotations |

## Engineering terms

| Term | Meaning |
|---|---|
| **Engineering request (ENQ-)** | A request for technical design or calculation work |
| **BOQ (BOQ-)** | Bill of Quantities: the contractor's list of every item and quantity a project needs |
| **BOM** | Bill of Materials: the raw materials and components that make one finished product |
| **CAD** | Computer-Aided Design drawings (DWG, DXF) |
| **BIM** | Building Information Modelling: 3D models (Revit RVT, IFC) |
| **Technical submittal (SUB-)** | A formal package of datasheets, certificates and drawings sent for project approval |
| **Datasheet** | A technical specification sheet for a product |
| **Revision** | A numbered version of a drawing or document |
| **Variant / article number** | One specific size or finish of a product, with its own code (for example FXR-4141-20) |
| **SKU** | Stock Keeping Unit: the product-level code |
| **Load capacity** | The maximum safe load (for example in kN) |
| **IS / ASCE / NFPA** | Engineering standards: Indian Standards, American Society of Civil Engineers, National Fire Protection Association |

## Supply chain and plant terms

| Term | Meaning |
|---|---|
| **PR (PR-)** | Purchase Requisition: an internal request to buy |
| **PO (PO-)** | Purchase Order: the formal order sent to a vendor |
| **GRN (GRN-)** | Goods Receipt Note: a record of material received from a vendor |
| **Vendor bill (VB-)** | A vendor's invoice to Fixotec |
| **MRP** | Material Requirements Planning: works out what to make or buy |
| **Safety stock** | The minimum buffer quantity to keep |
| **Reorder level** | The stock level that triggers replenishment |
| **Free stock** | On-hand stock minus stock already reserved for orders |
| **Weighted-average cost** | Stock valuation that averages the cost of all receipts |
| **Bin / zone** | A storage location / its type (RAW, WIP, FG, QC_HOLD, REJECTED, SCRAP) |
| **RAW / WIP / FG** | Raw material / work in progress / finished goods |
| **Production order (PRD-)** | An instruction to manufacture a quantity of a product |
| **Job card (JOB-)** | An operator's work instruction for one machine job |
| **Work centre / machine** | A production area / equipment (for example LASER-01) |
| **Downtime** | Time a job or machine is stopped |
| **OEE** | Overall Equipment Effectiveness (Roadmap metric) |
| **QC (QC-)** | Quality Control inspection: incoming, in-process or final |
| **Rework** | Fixing a defective product instead of scrapping it |
| **NCR (NCR-)** | Non-Conformance Report: a record of a quality failure |
| **CAPA** | Corrective And Preventive Action: the fix for an NCR, and how to stop it happening again |
| **Root cause** | The underlying reason a defect happened |
| **Dispatch (DSP-)** | A shipment of goods to a customer |
| **Pick list / picking** | The list of items to collect from the warehouse / collecting them |
| **LR number** | Lorry Receipt: the transporter's consignment number |
| **E-way bill** | The Indian GST electronic document required to move goods |
| **POD** | Proof of Delivery |

## Finance and tax

| Term | Meaning |
|---|---|
| **Invoice (INV-)** | A bill to the customer (one per dispatch, due in 30 days) |
| **Payment (PMT-)** | Money received from a customer or paid to a vendor |
| **Receivables / payables** | Money customers owe Fixotec / money Fixotec owes vendors |
| **Overdue** | Past the due date and still unpaid |
| **GST** | Goods and Services Tax (India) |
| **GSTIN** | GST Identification Number |
| **HSN** | Harmonized System of Nomenclature: the product tax classification code |
| **PAN** | Permanent Account Number (Indian tax ID) |
| **Cost centre / profit centre** | Accounting units for tracking spend / profit |
| **Expense claim (EXP-)** | An employee's reimbursement request |
| **Tally / Zoho Books** | Accounting software Fixotec ONE exports to |

## Field and service

| Term | Meaning |
|---|---|
| **Site issue (ISS-)** | A problem logged during installation at a project site |
| **Material shortage** | A site issue flag for missing material |
| **Service ticket (TKT-)** | A customer support or complaint case |
| **SLA** | Service Level Agreement: the response deadline by priority |
| **Milestone** | A key project stage: Lead, RFQ, Engineering, Quotation, Order, Production, Dispatch, Site |
| **Project health** | On Track, At Risk or Delayed, calculated automatically |

## Technical and platform terms

| Term | Meaning |
|---|---|
| **ERP** | Enterprise Resource Planning: the internal business system |
| **Portal** | The self-service app for external partners |
| **CMS** | Content Management System: where website content is edited |
| **RBAC** | Role-Based Access Control |
| **Permission** | `resource.action`, for example `quotations.approve` |
| **MFA / 2FA / TOTP** | Multi-factor authentication using 6-digit authenticator app codes |
| **SSO** | Single Sign-On (Google or Microsoft) |
| **Audit log** | A permanent record of who changed what, when, before and after |
| **Workflow / status machine** | The allowed status steps for a record |
| **Approval rule** | A condition that routes a record to an approver role |
| **Domain event** | A stored record of a business moment (for example `SalesOrderCreated`) |
| **Seed / demo data** | Sample data loaded by `pnpm db:seed` |
| **API / REST / Swagger** | The backend interface / its style / its interactive documentation |
| **Next.js / NestJS** | The front-end and back-end frameworks used |
| **PostgreSQL / Redis / BullMQ** | Database / cache and queue / background job library |
| **S3** | Amazon-style object storage for files |
| **Honeypot / CAPTCHA** | Anti-spam techniques on website forms |
| **Rate limit** | The maximum number of requests allowed in a time window |
| **Vercel** | Hosting platform for the three web apps |
